# Security

Daemonarium is a sandbox. A process that can escape it, or remote code execution in the kernel or a host, is a vulnerability.

Do not open a public issue for a process escape, a sandbox bypass, or remote code execution. Report it with GitHub private vulnerability reporting on the repository that contains the bug.

Give a version or commit, the host (Node, browser, or native), and a minimal recording or test that shows the escape. We will answer on that report. There is no public bounty.
